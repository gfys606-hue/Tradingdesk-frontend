# Trading Desk Frontend

Static React app (built with Vite) for the Paper Desk trading dashboard.
Talks to the trading-desk backend over HTTPS - enter your Render backend
URL on first load (gear icon to change it later).

## Local development

    npm install
    npm run dev

## Deploying on Render as a Static Site

Build command:

    npm install && npm run build

Publish directory:

    dist
